# 🐕 桌面宠物小狗

一个可爱的桌面宠物小狗应用，使用 Python 和 tkinter 制作。

## 功能特点

- 🎨 **可爱的小狗** - 巧克力色身体、三角形耳朵、圆圆的眼睛带高光、小舌头
- 🖱️ **拖拽移动** - 左键按住小狗可以拖拽到任意位置
- 📋 **右键菜单** - 右键点击弹出功能菜单
- 🎭 **自动动作** - 小狗会自动摇尾巴、走动（仅待机状态触发）
- ⌨️ **快捷键支持** - 方便的键盘控制
- 🪟 **窗口置顶** - 始终显示在桌面最上层
- 🎀 **可爱风格** - 温馨可爱的视觉效果

## 运行要求

- Python 3.6+
- tkinter（Python 标准库，通常已自带）

## 使用方法

```bash
python pet.py
```

## 快捷键

| 按键 | 功能 |
|------|------|
| `q` | 退出程序 |
| `w` | 让小狗走动 |
| `空格` | 让小狗做动作（摇尾巴+跳跃） |
| `s` | 让小狗坐下 |

## 右键菜单

右键点击小狗可以弹出菜单，包含：
- 🐾 走动
- 🐕 坐下
- ✨ 做动作
- 👋 退出

## 动画状态

| 状态 | 说明 |
|------|------|
| 待机 (idle) | 轻微浮动、尾巴慢摆、偶尔眨眼和伸舌头 |
| 走动 (walking) | 腿部交替摆动、摇尾巴、自动避障 |
| 坐下 (sitting) | 身体下移、后腿折叠，持续约6秒 |
| 做动作 (wagging) | 快速摇尾巴 + 跳跃，持续约3秒 |

## 技术实现

- 使用 `tkinter` 创建无边框透明窗口
- 使用 Canvas 绘制小狗图形（椭圆身体、三角形耳朵、圆形眼睛）
- 使用 `overrideredirect` 实现无边框
- 使用 `attributes('-transparentcolor')` 实现透明背景
- 使用 `attributes('-topmost')` 实现窗口置顶
- 双帧计数器：`anim_frame`（全局，用于持续动画）+ `state_frame`（状态内，用于限时动作）
